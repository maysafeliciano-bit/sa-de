# CUIDA+ 🏥💙

O CUIDA+ é um site informativo sobre saúde criado para facilitar o acesso a conteúdos de prevenção, bem-estar e cuidados básicos.

## 🎯 Objetivo

O projeto busca apresentar informações de saúde de forma simples, organizada e acessível.

## ✨ Funcionalidades

- Página inicial com apresentação do projeto
- Artigos sobre saúde e prevenção
- Busca por conteúdos
- Filtro por categorias
- Cards de artigos
- Área de dicas rápidas
- Design responsivo para celular, tablet e computador
